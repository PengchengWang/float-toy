FloatXX 使用示例

1. 创建预定义类型

const bf16 = FloatTypes.bf16(); // Brain Float 16 const tf32 = FloatTypes.tf32(); // Tensor Float 32

2. 创建自定义类型

const custom = FloatTypes.custom(1, 4, 7); // 1符号位 + 4指数位 + 7尾数位

3. 数值转换

const value = 3.14159; const bits = custom.fromNumber(value); const result = custom.toNumber();

4. 十六进制操作

const hex = custom.toHex(); custom.fromHex("4048");

5. 位字段分析

const fields = custom.getBitFields(); console.log(fields);

6. 创建整数类型

const int16 = FloatTypes.custom(1, 0, 15); // 16位整数
